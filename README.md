# AI Services API

Репозиторий проектов по проектированию и реализации API для интеллектуальных сервисов. Здесь собираются исходный код, описания архитектуры, контракты запросов и ответов, примеры данных и инструкции запуска.

Проекты посвящены взаимодействию внешних систем с алгоритмами обработки данных и моделями через HTTP API. Основные направления работы:

- проектирование REST API и обмен данными в формате JSON;
- разделение приложения на API, схемы данных, модель, бизнес-логику и хранилище;
- проверка входных данных и обработка ошибок;
- описание контрактов через OpenAPI и проверка запросов в Swagger UI;
- расчёт результатов, их хранение и получение;
- логирование запросов и времени обработки.

| Проект | Описание |

По мере развития репозитория будут добавляться новые сервисы и варианты архитектурных решений. Каждый проект размещается в отдельной папке со своим README, исходниками, зависимостями и примерами запросов.

## Организация репозитория

```text
AI_services_API/
  README.md
  LW_1. Designing an AI service using FastAPI/
    README.md
    main.py
    schemas.py
    model.py
    services.py
    storage.py
    requirements.txt
    examples/
```

Общий README описывает состав репозитория. Подробные сведения о конкретном сервисе, его API, расчётах и ограничениях находятся в README соответствующего проекта.

## Запуск проектов

Откройте нужную папку и следуйте инструкции в её README. Команды запуска выполняются из корня выбранного проекта, где находятся `main.py` и `requirements.txt`.

Для каждого проекта создаётся отдельное виртуальное окружение; зависимости устанавливаются из его `requirements.txt`.

Текущий сервис использует Python, FastAPI, Pydantic и Uvicorn. Его README содержит описание маршрутов, ограничения входных данных, примеры запросов и пояснения к расчёту риска.
